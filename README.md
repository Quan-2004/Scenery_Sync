## Running with Cloudinary

To run the app with Cloudinary integration enabled, use the following command:

```bash
flutter run --dart-define=CLOUDINARY_CLOUD_NAME=dvcebine7 --dart-define=CLOUDINARY_UPLOAD_PRESET=scenery_upload
```

Or use the **"scenery_sync (Cloudinary)"** launch configuration in VS Code.
